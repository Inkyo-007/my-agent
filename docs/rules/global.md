# 全局开发规范

## 项目摘要

该项目是一个个人 Agent 应用。应用部署在本地，目标是对齐业界领先的 Claude Code、Codex、OpenClaw 等参考系统，构建一套完整且实用的 Harness 系统，打造成一个完备的 Web 端 Agent 应用。

## 开发规范

- 先主动审查所有依赖与相关文件，再规划实现方案。
- 禁止假定、猜测任何实现；行为以代码与设计文档为准。
- 对参考信息有困惑时主动提问，不要带着歧义开工。
- 除非用户要求，否则保持最小化修改，不顺手重构无关代码。
- 永远保持项目工程化、整洁性、可维护性，合理拆分功能模块。
- 优先复用仓库现有的模式、组件与工具函数，不重复造轮子；引入新依赖、新抽象前必须有明确收益。
- 开发新内容前先判断是否需要补充 `.gitignore`，需要则先补充再开发。
- 永远以严谨负责的态度完成任务，认真思考任务要求，处理好所有细节！以最高标准要求自己的代码！
- 当项目有所变动，必须及时更新所有相关文档，确保文档与代码保持一致。
