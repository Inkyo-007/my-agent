## 后端

### tools 的分层缓存机制

在工具较多时，如果每次都将全部工具的 name 与 describe 都丢给 Agent，是一个很低效的行为，可能会引起上下文浪费、注意力缺失等问题。为此可以提出工具分层与缓存机制。

即，把工具分为三类：

- 常用工具：例如 read/grep/glob 等工具，此类工具常驻加载在上下文中。
- 缓存工具：近期使用过的其它工具，会放进缓存中，会随常用工具一同加载在上下文中。缓存工具会根据一定的算法进行更新。
- 非常用工具：除了上述工具的其它工具，此类工具只会在模型主动查询全部工具列表时才会显示。
